Чек-лист по описанию фичи за секунды

Чек-листы и баг-репорты из описания фичи. Всё в браузере, данные никуда не уходят.

Соберите пакет проверок на весь спринт

Впишите фичи спринта, по одной в строке, и получите чек-лист по каждой. Если для фичи нет правил, добавьте свои проверки прямо под ней.

Список можно вставить из таблицы (Excel, Jira): одна фича в строке. Учитываются первые 10 фич.

Пример подставится вместо текста в поле. Чтобы увидеть пример заново, удалите добавленное правило в разделе «Свои правила».

Баг-репорт для Jira и Excel

Заполните поля, получите готовый текст для Jira или файл для Excel.

Рутина, которую можно не повторять

Чек-листы и тест-кейсы каждый раз собираются с нуля, баг-репорты пишутся руками. Это время уходит на одно и то же.

Инструмент выбирает стартовую заготовку по ключевым словам из описания фичи. Вы правите её под проект и добавляете свои проверки.

Всё работает в браузере. Описания и правила никуда не отправляются.

Свои проверки для вашей темы

Встроенные темы знают пароли, формы, оплату и поиск. Если у вас другая тема, например склад, добавьте её сами. Сработает, когда это слово встретится в описании фичи.

Хотите ловить любые окончания слова? Поставьте * в конце: склад* найдёт «склад», «склада», «складе». Слово без * ищется целиком.
